## G. Security observations

The runtime does not serialize `TG_SECRET` to the frontend and `.env`/`.env.*` are git-ignored. The Commander-facing adapter is allowlisted and cannot send arbitrary GSQL. However, `scripts/serve_ui.ts` is a local development HTTP server, not a production-hardened API: it has no authentication, rate limit/body limit, security headers, or strict invalid-case rejection. These are explicit submission/deployment risks, not hidden from this assessment.
